Device API

Planned interface for authenticated telemetry and device commands.

POST/api/devices/{device_id}/telemetry
POST/api/devices/{device_id}/commands

FloraOS

Embedded control software for sensor integration, hardware abstraction, telemetry, and device-side automation. The firmware contract is not public yet.

Telemetry model

Initial device state is expected to carry timestamped sensor readings, node health, firmware version, uptime, and last-seen information.

Account security

The current backend uses hashed passwords and secure session cookies. Password reset, API keys, OAuth, and 2FA are logical next steps, but are not implemented yet.
