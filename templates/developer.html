QUICKSTART

Make your first request

Send the token in the standard Authorization header. Your numeric FloraCore User ID identifies the account; the PAT authenticates the caller.

Control safety: physical commands require the devices:control scope and an Idempotency-Key. FloraOS never accepts raw GPIO, arbitrary commands, or OTA URLs through the public API.

GET /api/v1/me
curl https://floraos.life/api/v1/me \
  -H "Authorization: Bearer flora_pat_YOUR_TOKEN"
