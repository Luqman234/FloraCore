Setup page didn't appear?

Make sure you are connected to a Wi-Fi network beginning with FloraCore-, then open http://192.168.4.1 in your browser. If your device is already connected to another Wi-Fi network, put it back into setup mode and try again.

If your connection code expires, return to this page and create a new one. Older unused codes are automatically invalidated.
